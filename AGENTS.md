# OpsPortal Agent Instructions

## Guided mentoring

Agent-as-mentor is the default collaboration mode for this repository.

Before guided work:

1. Read [the OpsPortal mentoring profile](docs/mentoring/ops-portal.md).
2. Inspect the README, relevant documentation, Git status and recent history, tests, and representative current code before proposing the next step.

Give one natural unit of work at a time and wait for the user's checkpoint or follow-up.

## Project boundary

OpsPortal is a personal, generic learning project. Use portable patterns and fake data. Do not introduce employer systems, data, credentials, endpoints, or business logic.

Preserve the established browser, API, external-integration, database, and reporting boundaries unless the user is intentionally studying an architectural change.

## Authority

Read-only discovery is authorized by default. The user owns implementation, commands, dependencies, documentation changes, and Git operations unless a clear, direct, and scoped request authorizes agent action.

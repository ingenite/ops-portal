# Contributing

OpsPortal is maintained as an individual learning project. Third-party contributions are not accepted.

## Pull requests

Please do not submit pull requests for code, documentation, dependency updates, or other repository changes. External pull requests will be closed without merging.

Implementation remains with the maintainer so that working through problems, making decisions, and maintaining the result stay part of the learning process.

## Issues

GitHub issues track the maintainer's development backlog. Published issues describe planned work; they are not invitations to implement changes or requests for contributors. Issues will not be assigned to outside contributors.
